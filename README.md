# SurfVT14 Game Builds

This repository is being prepared to hold the static game builds used by SurfVT14.

## Current status

Only this README is currently uploaded to GitHub. The game build files have not been uploaded yet because this session has no working Git push credential, and the connected GitHub tools cannot transfer the large binary build files.

A complete local Git repository has been prepared in the workspace at `/workspace/surfvt14-game-builds`, commit `2c678134254d6a49b98defe373238ca13b877e8a`. It contains the game builds listed below, without training builds.

## Planned contents

- 26 Subway Surfers maps, with available Unity files and per-map `unlock-all.js` and `infinite-save.js`.
- Subway Crackers and its save bootstrap/backup.
- Subway Moggers Lite and Ultimate.
- Venice modded and Venice Normal.
